1. Scenario 'urgency' (code: sim/airsim_vlm/closed_loop/damage_loop.py, SCENARIOS['urgency'], urgency_setup())
Step-6 city area: 600 x 600 m CityEnviron square, 87 merged footprints, disaster users (5 hotspots), 200 users/km^2 and
0.1/s/km^2 arrivals, T = 300 s, MAQAC-S (maqac_seq), onboard user perception, calibrated step-6 camera model for 'seen'.
Damage: step-3 label model, layout 'indep' (3 epicentres), seed = mission seed.
Damage enters URGENCY. g_u = max(1, max over footprints within R_B = 25 m of the user's home of g(y_b)), g = (1, 1.5, 2.5, 3).
gbar = mean of g_u over all users of the world (initial + arrivals). Each user's class is redrawn (stream rng([seed, 1417]),
one uniform per user) with
   P(emergency | u) = min(0.95, 0.35 g_u / gbar),
   P(realtime  | u) = (1 - P(emergency | u)) x 0.35 / 0.65,   P(best effort | u) = (1 - P(emergency | u)) x 0.30 / 0.65,
so the expected class mix is the default disaster mix (0.35, 0.35, 0.30) unless the 0.95 cap binds (realised shares
reported). The class sets w_cls (3, 2, 1), the decay mu, the minimum rate and the mean session length of the user
(its session-length draw is rescaled to the new class mean); nothing else changes.
J_true = sum_u w_cls(u) g_u frac_u (damage_loop.true_score, R_B = 25 m). The planner never sees g or the class until
attach (cls_visible False, as in all v3 runs); arm D gives it g(y_b) of seen buildings, arm A gives 1.

NOT FLOWN. By sec. 3 the step-15 flights are not run, the 4-arm pilot is not run, and no box is rented. B and C were
never run on these seeds. Reading: across fleet sizes 2-8 and planner service radii 50-150 m, with damage driving
urgency, knowing the true damage of seen buildings did not raise the damage-weighted session score (|gain| <= 0.17 % of
the score). The planner already serves 95-99 % of the attainable value; in the v3 radio model access is decided by SINR
and admission (admit_disc False), so r_s changes only the planner's footprint value, not who can be served, and building
weights mostly reorder users that are served anyway. The paper's C-vs-B claim therefore rests on the one-round bench
(fig:perc); fig_voi can be reported as the closed-loop value-of-information null result.
